Features

🇩🇪

German Language Support

Comprehensive support for German number words, including regional variants like Swiss German ("dreissig" instead of "dreißig").

🔢

Ordinal Numbers

Handles ordinal numbers like "erste", "zweite", "siebte" and returns them as strings with dots (e.g., "7.").

➖

Negative Numbers

Supports negative numbers with the "minus" prefix, including negative ordinals.

🚀

Large Numbers

Handles extremely large numbers up to 999 × 10^27, including million, milliarde, billion, and beyond.

💻

Command Line Interface

Use the command-line tool for quick conversions directly from your terminal.

🔧

Fault Tolerant

Handles various input formats, case insensitive, and includes Swiss variants (ß → ss).

Installation & Usage

Install via pip

pip install zahlwort2num

Command Line Usage

Use the command-line tool for quick conversions:

zahlwort2num-convert "eine Million siebenhunderteinundzwanzig"

Note: Use quotes around the input when it contains spaces.

Python Usage

import zahlwort2num as w2n

# Basic conversion
result = w2n.convert('Zweihundertfünfundzwanzig')
print(result)  # Output: 225

# Ordinal numbers
ordinal = w2n.convert('neunte')
print(ordinal)  # Output: '9.'

# Negative numbers
negative = w2n.convert('minus siebenhundert Millionen achtundsiebzig')
print(negative)  # Output: -700000078
